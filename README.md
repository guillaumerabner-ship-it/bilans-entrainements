# Bilans d'entraînements

Application Web installable de suivi des séances, exercices, progressions et vidéos.

## Développement local

```bash
python3 server.py
```

Puis ouvrir `http://localhost:8000`.

## Publication

La branche `main` est publiée automatiquement sur GitHub Pages par le workflow `deploy-pages.yml`. La publication ne contient que les fichiers nécessaires à l’application Web.

Consulter [DEPLOIEMENT-SMARTPHONE.md](DEPLOIEMENT-SMARTPHONE.md) pour la configuration Google OAuth et l’installation sur Samsung.
